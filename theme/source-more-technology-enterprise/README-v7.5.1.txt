Source More Enterprise Theme v7.5.1

Desktop mega-menu interaction hotfix:
- Opens Solutions, Industries, and Resources by mouse hover.
- Keeps the menu open while the pointer moves down into the dropdown.
- Adds a 320 ms guarded close delay to prevent accidental disappearance.
- Removes the need to click the arrow on desktop.
- Keeps destination links clickable normally.
- Preserves mobile/tablet accordion controls.
- Preserves keyboard focus and Escape/outside-click closing behavior.

Installation:
Appearance > Themes > Add New Theme > Upload Theme
Choose Replace current with uploaded, then refresh with Ctrl+F5.
