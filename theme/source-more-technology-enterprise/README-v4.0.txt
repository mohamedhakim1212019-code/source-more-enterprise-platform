SOURCE MORE TECHNOLOGY ENTERPRISE THEME v4.0.0

INSTALLATION
1. Upload and activate the theme.
2. Install and activate Polylang.
3. Add English (default) and Arabic.
4. Assign each page a language and connect translations.
5. Go to Settings > Source More Settings to update phone, email, WhatsApp, addresses and profile URL.
6. Add a Custom Logo under Appearance > Customize > Site Identity.
7. Clear WordPress/Hostinger caches.

BILINGUAL BEHAVIOR
- Header/footer labels switch automatically according to the active Polylang language.
- Arabic loads rtl.css and Cairo font.
- Links attempt to resolve the translated version of every page.
- Page body content remains editable as separate English and Arabic WordPress pages.

IMPORTANT
Keep page slugs consistent with the existing templates. Polylang may use translated URLs; the theme resolves translations by post ID when pages are linked.
