Production-ready foundation release.

Key additions:
- Secure AJAX contact form using wp_mail, nonce validation, consent and honeypot spam control.
- Industry detail pages for eight target sectors.
- WordPress search, archive, single-post and 404 templates.
- Breadcrumbs and baseline Organization schema.
- Blog/Insights page created by the starter installer.
- Expanded business settings for lead email and privacy URL.
- Accessibility and responsive refinements.

INSTALLATION
1. Upload the ZIP from Appearance > Themes > Add New.
2. Activate the theme. Existing page content is not overwritten.
3. Open Settings > Source More Settings and replace all placeholder contact details.
4. Configure SMTP using a reputable WordPress SMTP plugin for reliable delivery.
5. Assign menus under Appearance > Menus if custom navigation is preferred.
6. Add posts to populate the Insights/Knowledge Center.
