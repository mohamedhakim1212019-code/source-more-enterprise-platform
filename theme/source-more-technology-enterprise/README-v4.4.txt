SOURCE MORE TECHNOLOGY ENTERPRISE THEME — v4.4.0

Purpose
- Makes the theme portable to a fresh WordPress installation.
- Prevents blank About, Solutions, Industries, Resources, Contact, and service pages.

What is new
1. Automatic starter-site setup creates and publishes all required pages.
2. The correct bundled template is assigned to every page.
3. Slug-based template routing provides a second safety layer when a template was not selected manually.
4. WordPress is configured to use the created Home page as the static front page.
5. Added complete Industries and Resources pages.
6. Upgraded Contact page with contact methods and a starter inquiry form.
7. Existing page editor content is never overwritten.

After installation
- Replace/activate the theme.
- Visit WordPress Dashboard once while logged in as Administrator. This triggers the safe one-time setup.
- Open Pages > All Pages. The core pages should be present and published.
- Open Settings > Reading and confirm Home is selected as the homepage.
- Open Settings > Permalinks and click Save Changes if any URL returns 404.
- Clear Hostinger and browser cache.

Important
- Update phone, email, WhatsApp, and address in Appearance > Customize > Source More Settings.
- The fallback contact form uses the visitor's local email application. For reliable server-side delivery, add WPForms or Contact Form 7 shortcode/content to the Contact page editor; the theme automatically displays it instead of the fallback form.
