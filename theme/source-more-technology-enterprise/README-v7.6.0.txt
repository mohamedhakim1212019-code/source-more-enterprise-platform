INSTALLATION
1. Appearance > Themes > Add New Theme > Upload Theme.
2. Upload this ZIP and choose Replace current with uploaded.
3. Confirm Theme Version 7.6.0.
4. Visit Appearance > Bilingual Pages.
5. Click Create / Repair Bilingual Pages if any item is missing.
6. Open Settings > Permalinks and click Save Changes once.
7. Refresh the front end with Ctrl + F5.
