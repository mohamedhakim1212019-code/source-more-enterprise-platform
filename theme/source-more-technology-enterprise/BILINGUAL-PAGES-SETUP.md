## Creation workflow

1. Open **Pages → All Pages**.
2. Click the Arabic **+** beside the English page.
3. Enter the Arabic title.
4. Confirm the language is Arabic and the page is linked to the English original.
5. Select the same **Page Template** used by the English page.
6. Leave the Gutenberg content area empty to use the professionally written default bilingual template.
7. Publish and test the language switcher.

## Manual editing option

The built-in template is used only while the Gutenberg page content is empty. Adding any Gutenberg content replaces the default template for that page and language. This allows future custom editing without changing theme files.
