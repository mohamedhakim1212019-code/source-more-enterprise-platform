Source More Technology Enterprise Theme v7.7.0
================================================
Bilingual Products & Platform UI

Requires
- WordPress 6.4+
- Polylang with English and Arabic configured
- Source More Platform v3.8.0 for bilingual Product Quote, Fleet lead capture, and AI Assistant interfaces

Included
- English/Arabic Product Center archive labels and filters
- English/Arabic product detail experience
- Localized product pricing, availability, specifications, and quotation calls to action
- Language-aware Arabic /ar/products/ navigation
- Preserved bilingual Home, About, Solutions, Industries, Resources, Contact, and mega navigation

After installation
1. Save Settings > Permalinks.
2. Open Source More CRM > Products.
3. Use the Arabic + icon to create a translated version of each product that needs Arabic title, description, excerpt, and specifications.
4. Test /products/ and /ar/products/.
