Source More Enterprise Theme v7.3.4

Fixes
- Homepage Showcase Content fields now appear as a full-width editable meta box below the Gutenberg editor.
- The editor no longer depends on a Gutenberg sidebar API that may be unavailable in some WordPress versions.
- Arabic and English homepage values remain stored independently.
- Arabic hero headline size has been reduced for improved balance and readability.

Editing
1. Open Pages > Home or Pages > الرئيسية.
2. Scroll below the content editor to the Meta Boxes area.
3. Open Homepage Showcase Content / محتوى الصفحة الرئيسية.
4. Expand a section, edit its fields, then click Save/Update.
