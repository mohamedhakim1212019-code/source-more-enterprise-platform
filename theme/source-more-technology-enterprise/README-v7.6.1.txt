Source More Enterprise Theme v7.6.1

This maintenance release completes the Solutions navigation and simplifies internal-page hero presentation.

Changes
- New IT Consulting page in English and Arabic.
- New Digital Transformation page in English and Arabic.
- Direct working links from the Solutions mega menu.
- Bilingual Pages setup now creates and links the new pages under Solutions.
- Removed the small first hero line (eyebrow) from internal pages.
- Arabic textual brand references use سورس مور; the visual logo remains unchanged.

After installation
1. Open Appearance > Bilingual Pages.
2. Click Create / Repair Bilingual Pages.
3. Open Settings > Permalinks and click Save Changes.
4. Clear the browser cache with Ctrl + F5.
