SOURCE MORE TECHNOLOGY ENTERPRISE THEME — VERSION 4.5.0

Primary objective
Make the Fleet Savings Calculator the flagship homepage conversion feature and provide a complete, functional calculator page.

What is new
- Calculator spotlight moved directly below the homepage hero.
- Gold, animated calculator CTA made the primary hero action.
- Strong visual calculator preview with indicative metrics.
- Persistent floating calculator shortcut on all pages except the calculator itself.
- Fully functional browser-based Fleet Savings Calculator.
- Inputs for device count, mono/color volume, cost per page, and monthly fixed costs.
- Adjustable optimization potential from 5% to 35%.
- Instant outputs for current annual cost, optimized cost, annual savings, three-year savings, annual pages, cost breakdown, and average cost per device.
- Bilingual English/Arabic copy and responsive layouts.
- Clear estimation disclaimer and professional assessment CTA.

Upgrade
1. Appearance > Themes > Add New > Upload Theme.
2. Upload the v4.5 ZIP and choose Replace current with uploaded.
3. Keep/activate the theme.
4. Visit the WordPress dashboard once as Administrator.
5. Settings > Permalinks > Save Changes.
6. Clear Hostinger cache and browser cache.
7. Test the homepage and Fleet Savings Calculator in an incognito window.

Notes
The calculator is an indicative planning tool, not a quotation. It performs calculations locally in the visitor's browser and does not collect or transmit data.
