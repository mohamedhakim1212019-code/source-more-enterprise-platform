Source More Enterprise Theme v7.8.0
================================================
Visual Images & Final Experience Polish

Requires
- WordPress 6.4+
- Polylang with English and Arabic configured
- Source More Platform v3.8.0 for bilingual Products, Fleet, Quote, CRM, and AI Assistant functions

Included
- Optimized bundled WebP images for major website experiences
- Responsive photo heroes for Home, About, Solutions, Industries, Resources, Products, and Contact
- Service-specific visuals for managed print, infrastructure/cloud, and cybersecurity
- Appearance > Visual Media manager for non-code image replacement
- English and Arabic visual consistency with full RTL support
- Improved mobile layout, focus states, reduced-motion behavior, and image performance

After installation
1. Replace the current theme with this ZIP and confirm Version 7.8.0.
2. Open the homepage and press Ctrl+F5.
3. Review Home, About, Solutions, Products, Industries, Resources, Contact, and representative service pages in both languages.
4. Open Appearance > Visual Media to preview the bundled images or replace any image from the WordPress Media Library.
5. Test desktop, tablet, mobile, RTL, menu navigation, AI Assistant, Fleet Calculator, and Product Quote forms.

Visual image defaults
- Homepage hero: integrated business technology workplace
- About: leadership and advisory collaboration
- Products: modern technology showroom
- Print/document solutions: managed print workplace
- Infrastructure/cloud: modern server and cloud environment
- Cybersecurity: security operations center
- Industries/resources/contact: executive advisory and customer consultation

No database migration is required.
