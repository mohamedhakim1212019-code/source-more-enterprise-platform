Source More Enterprise Theme v7.4.1

Arabic footer and solution-process visual polish release.

Included improvements:
- Phone and email remain readable left-to-right inside RTL pages.
- Footer logo keeps the same mark/text order in both languages.
- Arabic footer branding uses “سورس مور”.
- Solution methodology steps use readable dark copy on premium white cards.
- Soft section background, borders, shadows, and hover elevation improve clarity.

Installation:
Appearance > Themes > Add New Theme > Upload Theme
Upload the ZIP and choose Replace current with uploaded.
Then confirm theme version 7.4.1 and press Ctrl+F5.
