POLYLANG PAGE SETUP
Create each Arabic translation by clicking the + icon beside the English page.
Keep the same page template as the English page.
Recommended Arabic titles:
- About Us -> من نحن
- Solutions -> الحلول
- Managed Print Services -> خدمات الطباعة المُدارة
- Enterprise Printing -> حلول الطباعة المؤسسية
- Document Management -> إدارة المستندات وسير العمل
- IT Infrastructure -> البنية التحتية لتكنولوجيا المعلومات
- Cloud & Microsoft Solutions -> حلول السحابة ومايكروسوفت
- Cybersecurity -> الأمن السيبراني
- Office Automation -> أتمتة بيئة العمل
- Annual Maintenance Contracts -> عقود الصيانة والدعم السنوي
