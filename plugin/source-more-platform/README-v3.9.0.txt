Source More Platform v3.9.0 — Enterprise Fleet Report Portal

Highlights
- Secure client report portal with branded URL structure.
- Three-page bilingual executive fleet assessment.
- KPI dashboard, cost analytics, five-year savings projection.
- Optimization opportunity matrix and environmental indicators.
- Book-assessment and WhatsApp calls to action.
- Print-optimized A4 PDF output.

Installation
Upload the ZIP from Plugins > Add New > Upload Plugin and replace the current version.
After upgrade, visit Settings > Permalinks once if the new /report/ URL does not open immediately.
Existing old report links remain supported.
