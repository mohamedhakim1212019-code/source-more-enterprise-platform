Source More Platform v3.8.0 — Bilingual Customer Experience
================================================================

This release makes the public Product Center, Fleet Assessment capture, AI Assistant, quotation forms, validation messages, and customer confirmations bilingual in English and Arabic.

Install
1. Replace the current Source More Platform plugin with this package.
2. Confirm Version 3.8.0 under Plugins.
3. Save Settings > Permalinks once so the Arabic Product Center archive resolves.
4. Clear browser and page caches.

Polylang
- Products, Product Categories, Brands, and AI Knowledge are registered as translatable content.
- Translate each published product by clicking the Arabic + icon in the Product list.
- Quote Requests, Leads, and Conversations remain internal CRM records and are not duplicated by language.

Scope note
- Fleet Calculator interface, lead form, validation, and customer email are bilingual.
- The existing downloadable Fleet PDF remains in English in this release to preserve reliable font rendering and token-protected delivery.

Database version remains 3.1.0. No schema migration is required.
