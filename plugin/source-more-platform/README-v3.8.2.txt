Source More Platform v3.8.2 — Fleet Report Header & Footer Refinement

Changes:
- Compact executive report header.
- Full Source More website logo in header and footer.
- Branded footer with phone, email, address, website, and report number.
- Business details are read from Settings > Source More Settings.
- Improved print pagination to avoid a footer-only final page.

Installation:
1. Upload the ZIP from WordPress > Plugins > Add New > Upload Plugin.
2. Replace the existing Source More Platform plugin when prompted.
3. Confirm version 3.8.2 under Plugins.
4. Update phone, email, and address in Settings > Source More Settings.
5. Generate a new Fleet Savings report and test Print / Save as PDF.
