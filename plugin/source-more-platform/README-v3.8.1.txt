Source More Platform v3.8.1 — Branded Bilingual Savings Report
================================================================

This maintenance release upgrades the Fleet Savings Calculator report.

Highlights
- Full Arabic report content with native RTL layout.
- Full English report content with LTR layout.
- Uses the active WordPress custom logo (or site icon as fallback).
- Executive Navy and Gold Source More design.
- Client profile, KPI cards, cost comparison, current environment, and recommendations.
- Clear report number and issue date.
- Print-optimized A4 output with a “Print / Save as PDF” button.
- Arabic text remains readable and searchable when saved as PDF from the browser.
- Existing secure, expiring report links remain compatible.

Install
1. Back up the current plugin.
2. Replace Source More Platform with this package.
3. Confirm Version 3.8.1 under Plugins.
4. Clear page/server cache.
5. Submit one English and one Arabic calculator test.
6. Open each report and choose Print / Save as PDF.

No database migration is required. Database version remains 3.1.0.
